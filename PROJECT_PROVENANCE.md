# Project provenance

This repository is a personal continuation of a completed collaborative practicum. It is not presented as work created by one person from the beginning.

## Contribution boundary

- The repository owner led the original data collection, preprocessing, early exploratory analysis, and the first half of the analytical work.
- Zhiyuan Zhao led later aggregation, visualization, Stage 2/Stage 3 extensions, and the first dashboard implementation.
- The current personal version selectively synchronizes that later work with permission, preserves the original analysis, rebuilds public-source acquisition paths, corrects statistical contracts, and rewrites the dashboard claims around reproducible evidence.

The synchronized donor snapshot is [`ZhiyuanZhaoMicheal/Practicum@1f63e190`](https://github.com/ZhiyuanZhaoMicheal/Practicum/tree/1f63e190ce280852d68945dbfce486075adda69b). Machine-readable import and source records live under `project/data/manifests/`.

## Third-party data boundary

Permission to reuse a collaborator's code does not grant permission to redistribute third-party datasets. In particular, EAGLE-I inputs remain partner-restricted and are used only for authorized local experiments. EAGLE-I-derived Stage 3 results also require a separate publication-rights review. A public release must exclude restricted raw data and verify repository history before publication.

Open-source software and public datasets retain their own licenses and terms. This file records provenance and attribution; it is not a repository license.
